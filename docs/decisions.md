# M0 decisions — 2026-09-24

1. **Separate application, Steam data and game locations.** The supplied JACK path is a directory; the executable is `Jack` inside it. The supplied Steam path is its data root; `steam` on PATH is the tested launcher location. Explicit flags, environment variables and ignored TOML override defaults. Other Steam libraries work through an explicit game-root path during M0; general VDF discovery remains M1.
2. **Run JACK from its own directory.** Confirmed `RPATH [.]`; use an argument array, explicit cwd and local library search path. The bundled shell wrapper does not change cwd and is poorly quoted for spaces, so direct binary launch is preferred. Actual native startup succeeded; no opaque configuration writer is justified.
3. **Use manual editor profiles.** The installed manual documents profiles and a Steam-edition automatic setup dialog, but no external configuration import contract. Supply the per-field recipe and locally generated values. The exact installed editor build and viewport/map round trip still require manual confirmation.
4. **Keep hltools as the M0 candidate.** Pin `fc5500439a04c3962e99af75589f96ca6b99afa5`, CPU Release build. Linux compilation and room BSP inspection succeeded. `-noembedsource` was verified against a positive control with embedded `source.map`. `-wadtextures` prevents the smoke fixture from copying stock texture pixels into its BSP. Upstream remains work in progress; actual engine loading is still pending.
5. **Keep a fallback available without silently switching.** The installed JACK bundle includes VHLT stage binaries and a source archive; these are an investigation candidate if engine testing exposes an hltools problem. Their source/license/build recipe has not been evaluated or pinned here. BSPGuy remains an optional later viewer; `hltools bsp info` suffices for structural M0 inspection. Hammer/Wine remains deferred.
6. **Measure reproducibility.** Two runs had identical non-entity lumps and different `compiled_at` entity timestamps. Removing that field in memory for comparison made the bytes equal; the actual artifacts were not normalized. Promise repeatable compilation, not identical BSP bytes.
7. **Keep acceptance honest.** The fixture was authored as text, not manually edited in JACK. Native window startup and valid BSP structure do not prove an editor save/reopen or engine playtest. Leave M0 open until those observations are recorded; do not advance to M1 claiming the exit criterion passed.
